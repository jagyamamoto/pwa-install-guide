「町内会で、少しスマホやパソコンに詳しい」くらいの前提で書いています。 専門用語が出てきたら、その都度かんたんに説明します。上から順に進めてください。

これは何をするページですか

あなたの町内会・団体のWebアプリに、「スマホのホーム画面にアイコンとして置いてもらうための案内」 という機能を追加する手順です。この機能自体は前のページで説明した通り、 実機で10回以上やり直して見つけた「迷わせない作り方」がすでに出来上がっています。 あなたがコードを書く必要はありません。AI（Claude Codeなど）に、この部品を渡して 「組み込んで」と頼むだけです。

前提条件

すでに動いている自分のWebアプリ（サイト）が必要です。まだ何もない場合は、 まず町内会向けアプリのひな形 kairanban-app を使うところから始めてください。そちらの 「AIコーディング初心者向け。最初に用意するもの」 ページに、アカウントの作り方や、AIにファイルを読ませる方法の基礎がまとまっています。 本ページはその続き（すでにAIコーディング環境がある前提）として読めます。

  1. この部品をダウンロードする

    GitHubのページを開き、 右上あたりにある緑色の「Code」ボタンを押して、「Download ZIP」を選んでください。 ダウンロードされたzipファイルを、ダブルクリックして展開（解凍）します。 gitというツールに慣れている方は、代わりに git clone でも構いません。

    git clone https://github.com/jagyamamoto/pwa-install-guide.git

    ↑ ターミナルが分かる方向けの、もう一つの方法です。分からなければ上のZIP方式で大丈夫です。

  2. 展開したフォルダを、自分のプロジェクトのフォルダのそばに置く

    自分のアプリのフォルダ（Claude Codeで普段開いているフォルダ）と、 いま展開した pwa-install-guide フォルダが、同じ場所からAIに見える状態 にしてください。分かりやすいのは、自分のプロジェクトフォルダの一つ上の階層に置く方法です。

  3. AIコーディングツールで、自分のプロジェクトを開く

    Claude Codeなど、普段AIにコードを書いてもらっているツールを開き、 自分のアプリのプロジェクトフォルダを開いてください（いつもの手順と同じです）。

  4. 依頼文をコピーして、AIに貼り付ける

    INTEGRATION.md というファイルを開いてください。AIへの依頼文がそのまま書いてあります。 文中の【プロジェクトのパス】と【この案件のログイン基盤・DB】の部分だけ、 自分のアプリの内容に書き換えて、それより下の全文をAIのチャット欄に貼り付けてEnterを押します。

    書き方に迷ったら、「〇〇（自分のアプリ名）に、この部品を組み込んでください」くらいの 一言を先頭に足すだけでも十分です。細かい判断はAIが行い、専門的な質問があれば 選択肢の形で聞き返してくるはずです。

  5. AIの質問には、選択肢から選ぶだけで答える

    依頼文の中に「仕様に関わる判断は、Yes/Noか選択肢で聞くこと」と書いてあるので、 専門用語で聞かれることはないはずです。もし専門用語で聞かれたら、 「非開発者にも分かる言葉で、選択肢にして」とだけ返してください。

  6. できあがったら、自分のiPhoneで実際に試す

    AIの作業が終わったら、「画面を見て終わり」にせず、実際に自分のiPhoneで 「ホーム画面に追加」を最初から最後までやってみてください。特に次の3つを確認します。

    • 案内の帯が、共有ボタンを隠していないか
    • いちばん小さい画面（iPhone SE等）でも、手順がすべて見えるか
    • ホーム画面から開いたときに「設定できました」と出るか

  7. 困ったとき

    AIが3回試しても解決しない場合や、ここまでの手順自体が分からない場合は、 GitHubのIssue に、今どういう状態か（何をしたか・何が起きたか）を書き込んでください。 コードが分からなくても、状況を書くだけで大丈夫です。

このページ自体、上と同じやり方でAIに作らせています。うまくいかない箇所があれば、 それも含めて教えてください。
